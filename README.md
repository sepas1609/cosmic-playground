# 🌌 Cosmic Playground — Interactive N-Body Particle Universe

A zero-dependency, real-time particle universe simulation powered by HTML5 Canvas and p5.js.

## 🎮 Controls & Interactions
- **Click & Drag**: Spawn planets and fling them with initial velocity vectors.
- **Move Mouse**: Attract nearby cosmic dust and create gravitational distortion.
- **Double Click**: Form a persistent gravity well / black hole anchor.
- **Spacebar**: Toggle pause / resume the cosmic time dilation.
- **C Key**: Clear canvas and reset cosmic particle field.
